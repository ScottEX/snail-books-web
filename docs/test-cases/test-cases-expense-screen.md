# 记账页面测试用例（ExpenseScreen）

## 模块一：每日对账模块

### 日期选择器
- [ ] 1.1 默认显示当天日期
- [ ] 1.2 点击日期可切换至其他日期
- [ ] 1.3 切换日期后，已录入数据不丢失（保留在当前日期）

### 实盘录入组
- [ ] 2.1 【卡余额】输入框可正常输入数字
- [ ] 2.2 【现金】输入框可正常输入数字
- [ ] 2.3 输入非数字时自动过滤/提示
- [ ] 2.4 输入负数时正常接受（表示透支/亏空）

### 渠道未到账录入组
- [ ] 3.1 五个渠道输入框（堂食/美团/饿了吗/团购/京东）均可独立输入
- [ ] 3.2 五个渠道之和自动计算并显示在汇总区
- [ ] 3.3 任一渠道输入变更，汇总值实时更新
- [ ] 3.4 全部为空时，汇总显示 0 或「—」

### 核算反馈看板
- [ ] 4.1 【账面余额】为系统计算项，不可编辑，字体为灰色
- [ ] 4.2 【对账差额】= 实盘（卡+现金）- 渠道未到账汇总
- [ ] 4.3 差额为正或0时，数字显示为绿色（#059669）
- [ ] 4.4 差额为负时，数字显示为红色（#8B1E22 或 #DC2626）
- [ ] 4.5 差额为大号加粗，视觉突出

### 边界情况
- [ ] 5.1 卡余额 + 现金 = 0，渠道全为 0 → 差额 = 0，绿色
- [ ] 5.2 仅填卡余额，其他为空 → 差额 = 卡余额，绿色
- [ ] 5.3 仅填渠道，实盘为空 → 差额 = 负数，红色
- [ ] 5.4 所有字段为大数字（百万级）→ 格式化正确（¥1,234,567）
- [ ] 5.5 输入小数（如 ¥123.45）→ 正常显示两位小数
