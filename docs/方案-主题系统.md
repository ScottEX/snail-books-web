一、 全局共用排版规范（所有主题通用）
这部分定义了字体的骨架，确保无论客户选哪个主题，界面的布局都是稳固的。
•	全局字体家族： font-family: "Inter", -apple-system, "PingFang SC", sans-serif;
•	数字等宽属性（对账必备）： font-variant-numeric: tabular-nums;
